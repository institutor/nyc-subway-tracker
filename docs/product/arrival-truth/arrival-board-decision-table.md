## Purpose and authority

This table provides explicit review outcomes for the [arrival admission and ordering contract](arrival-admission-and-ordering-contract.md) and the [reroute and track-conflict playbook](reroute-and-track-conflict-playbook.md). Each row proves that admission finishes before ordering, negative evidence is applied before positive prediction, only Live and Expected trains consume next-three slots, and a missing or suppressed primary row is not repaired with weak static evidence. It does not create new confidence states, freshness thresholds, service-change meanings, or rider language.

The [approved product specification](../../superpowers/specs/2026-07-30-nyc-subway-train-time-tracker-design.md) controls every conflict. Every row is **Pending** until its setup is exercised against a fixed reviewed product version, the actual result is recorded, and the Truth Gate accepts the evidence. An ordered decision and visible result written here are expected outcomes, not passing evidence.
