## Purpose and authority

This table provides explicit review outcomes for the [arrival admission and ordering contract](arrival-admission-and-ordering-contract.md). Each row proves that admission finishes before ordering, only Live and Expected trains consume next-three slots, and a missing primary row is not repaired with weak static evidence. It does not create new confidence states, freshness thresholds, or rider language.

The [approved product specification](../../superpowers/specs/2026-07-30-nyc-subway-train-time-tracker-design.md) controls every conflict. Every row is **Pending** until its setup is exercised against a fixed reviewed product version, the actual result is recorded, and the Truth Gate accepts the evidence. An ordered decision and visible result written here are expected outcomes, not passing evidence.

Each Truth Gate run must capture the following for every row: the setup actually exercised, the complete inputs, the admission gates in their applied order, the ordering calculation only after admission, the visible result, and confirmation that every prohibited result remained absent.

| Overlapping arrival ranges | Both trains are admitted before the overlap decision; Live wins only inside the supported overlap | Pending |
| Scenario 50 | Non-overlapping earlier Expected range center remains ahead of later Live trains | Pending |

Any failed prohibited-result check remains in the evidence record and must link its correction and rerun. No row becomes Approved merely because this table specifies the expected decision.
